# tmux

Шпаргалка по клавишам. Prefix — `C-a`. Полный список: `prefix + ?`.

## Панели и окна

| Клавиши | Действие |
|---|---|
| `h` `j` `k` `l` | перейти в pane |
| `C-h/j/k/l` (без prefix) | перейти в pane или сплит nvim (vim-tmux-navigator) |
| `Alt-Shift-H` / `Alt-Shift-L` (без prefix) | предыдущее / следующее окно |
| `c` | новое окно в текущем каталоге |
| `"` / `%` | сплит вниз / вправо в текущем каталоге |
| `z` | развернуть pane на весь экран и обратно |
| `x` / `&` | закрыть pane / окно |
| `1`…`9` / `n` / `a` | окно по номеру / следующее / последнее |
| `w` | дерево окон |
| `,` | переименовать окно |
| `!` | вынести pane в отдельное окно |
| `{` / `}` | поменять pane местами |
| `Alt-1`…`Alt-7` | раскладки pane |
| `Alt-стрелки` / `Ctrl-стрелки` | менять размер pane |

`prefix + p` больше не «предыдущее окно» — там floax, используй `Alt-Shift-H`.

## Плавающие окна

| Клавиши | Действие |
|---|---|
| `p` | floax: показать / спрятать плавающее окно (80%×80%, в каталоге текущего pane) |
| `P` | меню floax: размер, fullscreen, встроить как обычный pane |
| `Tab` / `Shift-Tab` | встроенный в tmux 3.8 плавающий pane (75%×30%, снизу по центру) |

Floax живёт в отдельной скрытой сессии: запущенное там (lazygit, сервер) продолжает работать, когда окно спрятано.

## Сессии

| Клавиши | Действие |
|---|---|
| `T` | sesh: выбор сессии (`^a` все, `^t` tmux, `^x` zoxide, `^d` убить) |
| `s` | дерево сессий |
| `g` | перейти в сессию (sessionist) |
| `C` / `X` | создать / убить сессию (sessionist) |
| `S` или `L` | предыдущая сессия |
| `@` | вынести pane в новую сессию |
| `$` | переименовать сессию |
| `d` | отключиться от сессии |
| `C-s` / `C-r` | сохранить / восстановить сессии (resurrect; continuum сохраняет сам каждые 10 мин) |

## Копирование

| Клавиши | Действие |
|---|---|
| `Space` | thumbs: хинты на хешах, путях, URL, IP. Строчная буква — скопировать, заглавная — скопировать и вставить |
| `u` | открыть URL с экрана через fzf |
| `[` | copy-mode: `v` начать выделение, `C-v` прямоугольное, `y` скопировать |
| `]` | вставить буфер |

## Служебное

| Клавиши | Действие |
|---|---|
| `r` | перезагрузить конфиг (`R` от tmux-sensible читает `~/.tmux.conf` — не он) |
| `I` / `U` / `Alt-u` | tpm: установить / обновить / удалить лишние плагины |
| `?` | список всех привязок |

## Установка

Плагины ставятся в `~/.config/tmux/plugins` (`prefix + I`). tmux-thumbs нужно собрать один раз (нужен Rust: `brew install rust`):

```sh
cd ~/.config/tmux/plugins/tmux-thumbs && cargo build --release
```
